## 1. 背景

收尾四块：① **能力补齐**（F3 wiki 双向/增量/冲突 · E3 spawn 削减收官）；② **口径与迁移**（术语统一 · A3 对外口径边界 · `MIGRATION.md` breaking 迁移节 · **K-1~K-4 竞品口径修订**）；③ **证据与链接清偿**（文档相对链接两级机检 · **证据入库清偿** —— 硬约束 14）；④ **3.0.0 release bump**。
