## 1. 背景

2.4.x 序列把「门禁强度」打到 PASS-with-issues 且无 P1，但仍攒下一批**防伪类弱判据**债：长度门槛、裸子串、字面连续等机械判据可被构造顶包。3.0 一次性收口为**语义边界判据**。

**2.4.2 对账（2026-09-15 · 逐条回源码核实）**：**R-2**（否定词表 + 同句共现窗口 `不[^。；\n]{0,12}通过` / `not\s*pass` · `cli-checks.ts:688`）· **R-3**（pin-16 无引号 HTML 属性三选一 · `cli-pins.ts:327`）· **R-4**（同句窗口）**均已交付，本波不再列**。本波只做**真残余**：R-5（`不\n通过` **跨行漏网** · 2.4.2 以 K 断言钉死防顺手修 · 显式留 3.0）等。

**判据两分原则（2026-09-15 裁决 · 硬约束 11）**：**防伪类判据继续语义化，自评类判据不语义化**。本波结论闸与 pins 语义化属**防伪**（防「没通过写成通过」· 防版本串漂移），照做；KPI 属**自评**（给思考打分），设机械门槛会反向约束思考（维护者原文：「补了语义可能还会限制思考」），**不做**。二者边界须在 W4 评审文中**显式写明**，避免后续波次把「语义化」当成无差别升级。

**KPI 实测数据（裁决依据 · 74 份任务盘点）**：37 份有 KPI 节（100% 只用 `Task_KPI%` · D1–D5 表与四维 1–5 两形态零采用）；分数 min 90 / max 100 / 中位 96 / 均值 96.8（18/37 满分 · 值域压缩区分度趋零）；`kpi_aggregator` 27/27 全为 `CLOSE`（`00` 档零采用）；`KPI_RUBRIC_v1_2` 被每份引用但**评分表本体不随包**（真值在私仓）→ 包消费者见引用、见不到规则。**裁决**：① 取消「每帽 KPI」设想（从未实现 · 不再作规划项）；② 不补语义闸；③ `close_kpi` 本体维持现状（仅存在性约束 · 零变更 · 不移除该节）。**遗留口径登记**：RUBRIC 引而不随包问题本波不处理（若日后动 · 归 W7 对外口径）。

## 5. 设计

### 5.1 结论闸语义闸（NEW-5 · 档位以评审文定稿）

从「长度 ≥ 20」升级为「语义组合命中」：签收主体 + 对象 + 结论动词共现（具体形态集合与误伤档位由评审文据存量合规率实测定夺）。判据属防伪类（防「没通过写成通过」）。

### 5.2 跨行否定封堵（R-5）

在 2.4.2 同句窗口（`不[^。；\n]{0,12}通过`）基础上，增加**跨行形态**判定；2.4.2 的 K 断言（钉死现行漏网行为）本波解锁后须同步更新为新语义的回归锁。

### 5.3 词表广义化（NEW-11）

跨语言常见否定形态入词表；**口径：常见形态覆盖 + 残余显式登记，不承诺完备**（评审文列已覆盖形态清单与已知残余）。

### 5.4 pin-17 / pin-08 语义绑定

- pin-17：在 2.4 W1「词锚 ∧ 表行」双命中基础上，升级为「宿主 id 落**主键列** + **表头结构**」双命中（防伪表行顶包）。
- pin-08：版本串须与**发布态措辞**绑定（如 `published` / 状态格语义），仅边界完整不算过。

### 5.5 exempt 真实性（NEW-10）

`authorized_by` 从「非空字符串」升级为真实性核验（形态以评审文定稿：如授权出处可溯）；`close` 与裸 `verify` 对 exempt 的消费逻辑统一（消除分叉）。

1. **每条负向 fixture 修复前真红、修复后转绿**（NEW-5 填充顶包 · R-5 跨行形态 · NEW-4 伪表行 · pin-08 版本串漂移 · NEW-10 假授权）——全部固化为回归锁。

4. **评审文落盘**且含**防伪/自评边界显式声明**（硬约束 11 兑现面）。
5. R-5 修复后 2.4.2 K 断言同步更新为新语义回归锁（不留过时断言）。
6. `npm run typecheck` 0 错 · `npm test` 全绿（含新增）· `pins check` 17/17。
