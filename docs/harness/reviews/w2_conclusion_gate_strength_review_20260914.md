## 4. 定档结论

**采纳 S1 微调档：`S1 · N=20`**——判据 = 结论/签收节合并文本**去除全部通过词命中后，残余非空白字符数 ≥ 20**（标题行计入节文本 · 与现行抽取一致）。

- **定档理由**：存量 48 份现行 PASS 文零误伤（可枚举 = 0）；攻击形态稳杀（残余 ~4 字符 << 20）；N 取值不再主观——由实测分布（min=40）取半定档，余量 2 倍。
- **不追溯存量（D-24-W2-NO-RETRO）**：新判据仅随新关账/新 verify 生效；存量 done task 不因本档重新打红。**波及处置路径**（循 2.3.1 N11 先例）：若有波及条目 → 逐条入 `docs/harness/legacy-gate-exempt.yaml` reviews 节（**四字段齐**：`slug` / `reason` / `date` / `authorized_by` · **`authorized_by` 值加引号**（`"00"` 防 yaml 整型 falsy · N13 已修显式类型判）· reason 点名本波接线波及）→ 裸 verify 复跑 PASS 且豁免命中留痕数与登记一致。
- **本次实测波及 = 0**（S1·N=20 对全部 48 份现行 PASS 文零误伤）→ 落地时登记「**零波及**」结论于 task 自检结论节，**预期无需新增豁免条目**；若 30 全量复测出现模拟面外波及（如 reviews/ 第二目录或 active 面样本），按上路径逐条处置，非静默放过。
